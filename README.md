# ssrobot
A small simulator-neutral robot interface for planning, policies, and real-world execution.

See [docs/architecture.md](docs/architecture.md) for the charter: scope, ownership,
non-goals, and the architecture decisions that bind v0.1, and
[docs/contracts.md](docs/contracts.md) for the public types, conventions, and wire
schemas. [docs/packages.md](docs/packages.md) describes portable robot packages.
